# Contributing to NEXUS Sovereign AI

Thank you for your interest in contributing to **NEXUS Sovereign AI**!

## 🛠️ Code Conventions & Guidelines

1. **Commit Message Format**: Follow conventional commits:
   - `feat(scope): add new feature`
   - `fix(scope): fix bug`
   - `docs(scope): update documentation`
   - `style(scope): design or CSS changes`
   - `refactor(scope): code restructuring`

2. **TypeScript & Python Standards**:
   - Run `npm run build` before submitting a PR to verify zero TypeScript errors.
   - Use strict type annotations and avoid `any`.

3. **Submitting Pull Requests**:
   - Create a feature branch (`git checkout -b feat/my-feature`).
   - Push your branch (`git push origin feat/my-feature`).
   - Open a Pull Request on GitHub describing your changes.
